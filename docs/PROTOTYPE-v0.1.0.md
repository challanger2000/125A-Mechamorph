# Prototype v0.1.0 — Proof of Concept

## Goal

Prove or disprove the core concept with the smallest useful machine.

### Success criterion

A clean modern synth signal should emerge sounding as if it is physically driven through / generated by a coherent old mechanical apparatus.

It must not sound like:

> dry synth + random mechanical noise

It should sound like:

> one machine that happens to be playing the synth material

---

## First machine

**Crank Machine**

Minimal modules:

1. DRIVE
2. GEAR
3. RATCHET
4. WOOD BODY
5. METAL RATTLE
6. AIR / BELLOWS

---

## Signal concept

```
                    +--> GEAR
                    +--> RATCHET
MECHANICAL DRIVE ---+--> RATTLE
                    +--> AIR
                    |
INPUT --> TRANSFORM +--> SHARED BODY --> OUTPUT
```

The mechanical state modulates both the input transform and the generated machine components.

---

## Core shared state

- crankSpeed
- crankPhase
- load
- wear
- pressure
- backlash
- looseness

---

## First user controls

Keep the first prototype intentionally small.

- MECHANIZE
- CRANK
- CLATTER
- WOBBLE
- AIR
- BODY
- WEAR
- OUTPUT

### Mapping philosophy

0% must be neutral / off where applicable.

Musically useful behaviour should concentrate roughly in the 20–50% region, clearly audible behaviour in 50–75%, and strong / creative behaviour in 75–100%.

---

## DSP experiments

### Drive oscillator / phase model
Generate one mechanical phase accumulator.

Use it to derive:
- slight speed drift
- periodic amplitude motion
- gear event timing
- bellows pressure
- coherent wobble

### Gear generator
Start with:
- tooth count
- mesh pulse frequency
- small eccentricity
- backlash delay
- material resonator

### Ratchet generator
- impulse train
- slight timing variance based on wear
- per-hit level variation
- shared body excitation

### Rattle generator
- primary transient triggers a small random cluster of secondary impacts
- probability and density increase with looseness / wear
- all impacts excite one or more body modes

### Air generator
- filtered noise
- amplitude tied to pressure
- optional valve chuff on strong input transients
- leak component

### Shared body
Initial body:
- small wooden cabinet
- modal resonator bank
- input and mechanical events feed the same resonator network

## Prototype test material

Use at least:

1. simple mono saw lead
2. polyphonic pad
3. piano
4. vocal phrase
5. drum loop
6. metallic percussion

The concept is only useful if it works on more than monophonic melodic input.

---

## Rejection conditions

Stop or redesign before adding further machine types if:

- mechanical layer sounds detached
- result is indistinguishable from generic lo-fi
- strong settings destroy musical readability too quickly
- effect requires pitch tracking to be convincing
- body resonators produce uncontrolled ringing
- generated noises become repetitive within short listening periods
