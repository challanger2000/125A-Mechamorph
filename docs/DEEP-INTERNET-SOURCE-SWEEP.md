# Deep Internet Sweep — Mechanical Identity Sources

Purpose: broaden Mechamorph beyond obvious "gear/ratchet" sounds and collect real-world mechanical gestures from many machine families.

## Search principle

Do not search only for "mechanical SFX".

Search for real devices that contain:
- repetitive contact
- indexed motion
- spring return
- ratchets
- rollers
- gears
- linkages
- cams
- friction
- pressure release
- chain drive
- carriage return
- detents
- bearings
- stepper motion

These often provide more authentic mechanical identity than generic designed "steampunk" effects.

Particularly promising categories:

- old machines

Entry/reference:
https://tmhsdigital.github.io/Free-Game-Dev-Assets/entry/bigsoundbank/

## Freesound

Continue prioritizing:
- CC0 only for embedded assets
- real recordings over designed SFX
- high-resolution sources where possible

Useful CC0-heavy uploaders found:
- Rudmer_Rotteveel
- Breviceps
- qubodup (verify each asset)
- Sadiquecat
- Mihacappy
- Krokulator

## OpenGameArt

Useful:

## Wikimedia Commons

Useful public-domain / CC0 sources:
- steam engine recordings
- mechanical keyboard recordings
- some machinery recordings

Each file license must be checked individually; many Work With Sounds files are CC-BY rather than CC0.

## USC Sound Effect Archive / Internet Archive

Historical Hollywood sound-effect collections from the 1930s/40s are available via Internet Archive.

Potential value:
- period machinery
- motors
- factory equipment
- mechanical props
- old vehicles
- switches/doors

Before embedding any individual file:
- verify the exact recording's public-domain status and source metadata.

Research lead:
https://archive.org/details/usc-sound-effect-archive

## GitHub CC0 collections

Examples:
https://github.com/code4fukui/sound-cc0

# Recommended hybrid machine palette

For the next serious Mechamorph prototype, do not start with dozens of random samples.

Build a small curated palette:

## Drive bed
1. real old crank machine
2. sewing machine slow
3. printing press
4. bicycle freewheel/drive

## Indexed contacts
5. turnstile ratchet
6. ratchet wrench slow/fast
7. calculator-printer indexing
8. typewriter carriage reset

## Actuation
9. lever
10. camera advance/shutter
11. lock/latch
12. rotary switch

## Return / spring
13. spring recording
14. mechanical keyboard/buckling spring
15. cassette/tape eject

## Friction
16. squeaky crank machine
17. bearing squeal
18. hinge/friction
19. old mechanism

## Loose hardware
20. washer/bolt rattle
21. chain
22. thin sheet metal
23. screws/coins

## Pressure event
24. Victorian steam escape valve
25. air/pneumatic release
26. pump/bellows

## Body
27. Heidelberg press body
28. old calculator/printer body
29. wood cabinet hits
30. thin metal cabinet/plate

This gives enough variety to create a machine that is not recognizably one sampled appliance, while every layer still has authentic mechanical identity.
