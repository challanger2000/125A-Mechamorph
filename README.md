# 125A Mechamorph

**Mechanical transformation FX for turning modern audio into physical, imperfect and characterful machine-driven sound.**

> Modern sound in. Mechanical machine out.

## Concept

Mechamorph is not intended to be another barrel-organ instrument or generic lo-fi effect.

The aim is to transform modern audio so that it appears to be produced, driven or transmitted by a coherent physical music machine: gears, ratchets, bellows, valves, springs, friction, loose metal, wood bodies and other mechanical systems.

## Development status

Current research branch: `v0.1.0`

The first milestone is a deliberately small proof of concept: a crank-driven machine combining shared motion, gears, ratchet, wooden body, metal rattle and air/bellows behaviour.

## Core rule

Mechanical noises must not merely be layered under the input.

The input and the generated mechanical elements should share motion, excitation, resonances and physical state so that the listener perceives **one coherent machine**.
